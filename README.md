## 宝塔建站对VPS的真实配置要求：512MB能不能用？

先把最基础的问题说清楚。宝塔官方给的最低配置是 512MB 内存、5GB 硬盘，系统选 CentOS 7.1+ 或 Ubuntu 16.04+，架构 x86_64。这个数字是真能跑起来的，纯面板本身只占 60MB 左右内存、20MB 左右磁盘。

但"能跑起来"和"好用"是两码事。实测下来，512MB 装**旧版** MySQL + PHP 勉强够，可一旦你装新版 MySQL 8.0 或 MariaDB 10.6，再配上 PHP 8.3——这是现在 WordPress 推荐的组合——512MB 基本就是"开机即爆"的状态。多个过来人的经验是：**装新版 LNMP 环境，至少要 1GB 内存才稳**，想跑得舒服、能扛几个站点同时在线，2GB 起步比较踏实。

整理一下宝塔建站VPS的配置梯度：

- **极限低配（512MB / 5GB）**：只能装旧版 LNMP，单站点、低流量，随时可能 OOM，不推荐生产用
- **入门可用（1GB / 10GB）**：能装新版 LNMP，跑单个 WordPress 博客没问题，适合个人站
- **舒适起步（2GB / 20GB）**：多站点、装点插件、跑点缓存，日常不卡，性价比甜点
- **进阶建站（4GB / 30GB+）**：多站点 + 数据库稍重 + 并发上来，外贸站、企业站这个档比较合适

CPU 这块，宝塔本身不怎么挑，1 核就能转，但 2 核在装环境、跑备份、应对流量高峰时会明显从容很多。硬盘记得选 SSD 或 NVMe，机械盘装宝塔就是给自己找罪受。

## 宝塔面板安装与建站流程：从裸机到上线

选定套餐、部署好 VPS 之后，剩下的流程其实各家 VPS 都通用，Evoxt 也不例外。整个链路用一句话概括：**买VPS → SSH连接 → 一行命令装宝塔 → 宝塔里装LNMP → 域名解析 → 添加站点 → 一键部署WordPress**。

**第一步：SSH 连接**
拿到 VPS 的 IP 和 root 密码后，用终端（Mac/Linux）或 PuTTY/Xshell（Windows）连上去：
bash
ssh root@你的VPS_IP


**第二步：安装宝塔面板**
根据系统选对应命令，CentOS 是：
bash
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec

Ubuntu/Debian 类似，换用 `install_6.0_ubuntu.sh`。装完会给你面板地址、账号、密码，记好。

**第三步：装 LNMP 环境**
首次登录宝塔面板，会弹窗让你选装 LAMP 还是 LNMP。**建站推荐 LNMP**（Nginx + MySQL + PHP），资源占用比 Apache 低。版本建议 Nginx 1.24+、MySQL 8.0 或 MariaDB 10.6、PHP 8.3。编译安装大概 20–40 分钟，取决于 VPS 性能——这正是高频 CPU 发挥作用的地方，Evoxt 这种 6.0 GHz 的机器编译会快不少。

**第四步：域名解析 + 添加站点**
去域名商那里把 A 记录指向 VPS IP，回宝塔"网站 → 添加站点"，填域名、选 PHP 版本、建数据库。

**第五步：一键部署 WordPress**
宝塔后台"网站 → 一键部署"里有 WordPress 模板，点一下、填数据库信息、设管理员账号，10 分钟内就能出站。

> 小提示：内存小的 VPS（1GB 及以下）装完宝塔后，建议在"Linux 工具箱 → Swap/虚拟内存"里加一个和内存等量的 Swap，能有效缓解 OOM 问题。

**Q：512MB 的 VM-0.5 能跑宝塔 + WordPress 吗？**
